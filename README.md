# GoCamp International

The application lives in [`cloudflare-app`](cloudflare-app/README.md): React Router,
Cloudflare Workers, D1 and R2. PHP, the external database gateway, and FTP deployment
tools have been retired. Existing `.php` URL aliases are handled by React Router.

Start with the app README for local development and validation. Migration records
are retained in `cloudflare-app/docs/archive` as history, not current setup instructions.
