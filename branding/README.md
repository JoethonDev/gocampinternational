# Brand source files

Place the **original** GoCamp logo here. Do not put a screenshot or a logo with a baked-in white/coloured background.

Preferred filename:

```text
branding/logo-source.png
```

Also accepted: `logo-source.svg`, `logo-source.webp`, `logo-source.avif`.

Requirements:

- transparent background;
- at least 600 px wide (the public header displays it at 60 px high);
- original colours, not a compressed screenshot;
- do not overwrite `images/logo.webp` (that original is used for social/Open Graph previews).

After adding the file, tell the agent the exact filename. The agent will create the optimized transparent header asset at `images/logo-transparent.webp` and update the site configuration if needed.
